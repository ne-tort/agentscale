# Ретроспектива волны 1 миграции на plugin-модули (v4)

**Период:** 2026-11-07…2026-11-08, worktree `wt-migration` (ветка `main`, dev-контур).
**Источник истины:** [`docs/ARCHITECTURE/plugin-architecture-complete.md`](../ARCHITECTURE/plugin-architecture-complete.md) (v4), [`docs/migration/plugin-migration-plan.md`](plugin-migration-plan.md), [`docs/migration/plugin-acceptance-map.md`](plugin-acceptance-map.md), [`docs/migration/plugin-test-plan.md`](plugin-test-plan.md), [`docs/migration/minio-sts-verification.md`](minio-sts-verification.md), [`docs/migration/plugin-network-alignment.md`](plugin-network-alignment.md), реестр ADR [`docs/architecture-migration/README.md`](../architecture-migration/README.md).
**Правила волны:** субагенты владеют своими каталогами, не трогают общие точки входа; тесты пишутся, но **не запускаются** (verification freeze); коммиты делает родитель.
**Статус документа:** только чтение + 2 новых файла в `docs/migration/`; код, конфиги, существующие `docs/**` не изменялись. Тесты/сборки/линт/`git`/`kubectl`/`kustomize`/`cosign`/`psql` не запускались.

### 4.1 F11-адаптеры (приоритет P0/P1)
