### Какая сторона дефекта

Для каждого падения реши, что именно неверно:

- **продакшн-код нарушает контракт** → чини код;
- **тест моделирует невозможное состояние или ожидает устаревший формат** → чини тест,
  и объясни в комментарии, почему прежнее ожидание было неверным.

Категорически нельзя «зеленить» прогон ослаблением проверки, удалением теста или
подгонкой ожидания под текущее (возможно, дефектное) поведение. Тест, который перестал
ловить дефект, хуже отсутствующего.

## Жёсткие правила

1. **Файловые операции — только нативными инструментами** (`read`/`write`/`edit`/`glob`/`grep`),
   не через shell (`cat`, `sed`, heredoc). Кириллица в shell-выводе ломается.
2. **Своя зона.** Редактируй только файлы из своей зоны. Чужие зоны можно читать, но не менять.
3. **Не отменяй и не «чисти» изменения других агентов** (никаких `git checkout`, удаления
   незнакомых файлов, перезаписи общих файлов целиком).
4. **Fail-closed по умолчанию.** Негативные пути (нет контекста тенанта, чужая область,
   устаревшая генерация, неизвестный исход провайдера) должны отказывать, а не деградировать.
5. **Идемпотентность и детерминизм.** Повтор с тем же ключом/дайджестом возвращает исходный
   результат; изменённый дайджест — конфликт, а не перезапись.
6. **Секреты и сырые payload в audit/quarantine не попадают** — только redacted reason code.
7. **Не коммить** — коммиты делает родительский агент. Не запускай `git add/commit/push`.

## Финальный отчёт — обязателен всегда

По завершении (или при невозможности завершить) **отправь отчёт родительскому агенту через
`send_message`** и никуда больше. Обычный финальный ответ в чате отчётом не считается.
Отчёт содержит:

- Task ID и статус (`done` / `partial` / `blocked`);
- **фактический результат pytest** — число `passed`/`failed` и команда, которой проверял;
- что изучено и что изменено, полный список затронутых файлов;
- для каждого исправленного падения — сторона дефекта (код или тест) и почему;
- нерешённые риски и блокеры с точной причиной.

Отчёт обязателен даже если ты ничего не изменил или задача заблокирована.
